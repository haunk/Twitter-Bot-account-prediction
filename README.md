## Problem Overview

This is a Kaggle in-class competition (CS610, SMU) focused on **anomaly detection**: building a model to identify sophisticated Twitter bot accounts from genuine users.

| Detail | Value |
|--------|-------|
| Task | Binary classification (bot vs. genuine) |
| Metric | AUC (Area Under ROC Curve) |
| Train set | 26,206 rows |
| Test set | ~11,000 rows |
| Public leaderboard | 30% of test set |
| Private leaderboard | 70% of test set (final ranking) |

---

## Dataset

Features extracted from Twitter account profiles, including:

- **Account metadata**: `followers_count`, `friends_count`, `statuses_count`, `favourites_count`, `account_age_days`, `average_tweets_per_day`
- **Profile flags**: `default_profile`, `default_profile_image`, `geo_enabled`, `verified`
- **Text fields**: `description`, `screen_name`, `location`, `lang`
- **URL fields**: `profile_image_url`, `profile_background_image_url`

## Feature Engineering

All features are generated by the `feature_engineer()` function applied to both train and test sets.

### Date/Time Features
- `account_hour`, `account_dayofweek`, `account_year` extracted from `created_at`

### Ratio Features
- `followers_friends_ratio`, `friends_followers_ratio`
- `tweet_per_follower`, `favourite_per_follower`
- `tweet_per_age`, `favourite_per_age`, `followers_per_age`, `friends_per_age`
- `engagement_ratio`: combined activity normalised by followers

### Text and Screen Name Features
- `description_length`, `has_description`, `description_word_cnt`, `has_url_in_desc`
- `desc_has_emoji`, `desc_special_char_cnt`
- `screen_name_len`, `screen_name_digits`, `screen_name_digit_ratio`
- `screen_name_underscore`, `screen_name_upper_cnt`

### Profile and Location Flags
- `has_location`, `has_custom_bg_image`
- `has_custom_profile_image` **dropped** (zero variance in test set: 100% are 1)

### Feature Crosses (bot-signal interactions)
- `cross_default_x_no_geo`, `cross_default_x_no_desc`
- `cross_defimg_x_no_geo`, `cross_defimg_x_no_desc`, `cross_defimg_x_default`
- `cross_triple_bare`: all three "bare profile" flags at once (strong bot signal)
- `cross_tweetrate_x_defimg`, `cross_tweetrate_x_no_geo`
- `cross_ffr_x_young`, `cross_age_x_defimg`

### Data Quality Decisions
- **`has_custom_profile_image` removed**: complete separation in train but zero variance in test, so it adds noise with no predictive value.
- **`verified` kept**: extremely rare in bots (near-complete separation), still useful as a feature.
- Language encoded via `LabelEncoder` fitted on combined train and test sets.

## Models and Results

All models use **10-fold Stratified Cross-Validation**. Hyperparameters tuned with **Optuna (50 trials, 5-fold inner CV)**.

| Model | OOF AUC |
|-------|---------|
| Logistic Regression (baseline) | ~0.920 |
| LightGBM | ~0.942 |
| XGBoost | ~0.941 |
| CatBoost | ~0.941 |
| Random Forest | ~0.934 |
| **Ensemble (best)** | **~0.9448** |

### Key Hyperparameters

**LightGBM**
```python
learning_rate=0.0355, num_leaves=119, min_child_samples=17,
subsample=0.606, colsample_bytree=0.534, reg_alpha=0.019, reg_lambda=1.85
```

**XGBoost**
```python
learning_rate=0.0322, max_depth=8, subsample=0.809,
colsample_bytree=0.780, reg_alpha=2.89, reg_lambda=0.117
```

**CatBoost**
```python
learning_rate=0.0142, depth=8, l2_leaf_reg=9.87,
subsample=0.660, colsample_bylevel=0.831, min_child_samples=61
```

**Random Forest**
```python
n_estimators=1242, max_depth=27, min_samples_leaf=3,
min_samples_split=8, max_features=0.5
```

## Ensemble Strategy

Four ensemble methods were evaluated; the best-scoring is selected automatically for submission:

| Method | Description |
|--------|-------------|
| Simple Average | Equal weight on LGB + XGB + CatBoost |
| Weighted Average | Weight proportional to each model's OOF AUC |
| Rank Average | Convert predictions to ranks before averaging; directly optimises for AUC |
| RF Blend (8%) | `0.92 x 3-model ensemble + 0.08 x RF`; RF contribution found by grid sweep |

> Multi-seed averaging was tested but showed no consistent improvement and was removed.

**Submission blending**: the two best-scoring submissions were also averaged for the final entry.

## Notes
- Random seed is fixed at `42` throughout for reproducibility.
- Early stopping (`patience=50`) is used for all boosting models to prevent overfitting.
- OOF (Out-of-Fold) predictions are used for all ensemble scoring to avoid leakage.
